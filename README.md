# Win Archive Compact Manager (WACM)

**Win Archive Compact Manager** は、Windows標準の透過圧縮をGUIから安全に管理するためのWindows向けユーティリティです。

対応方式は **NTFS / XPRESS4K / XPRESS8K / XPRESS16K / LZX**。ZIPや7zのような別アーカイブを作成せず、ファイル名・拡張子・論理内容を維持したまま、NTFS/WOFの仕組みで保存容量を削減します。

## 主な機能

- 5種類のWindows標準透過圧縮
- 圧縮解除、圧縮状態解析、容量集計
- ファイル／フォルダーのドラッグ＆ドロップ、貼り付け、参照
- 既に同じ方式で圧縮済みのファイルを高速スキップ
- 圧縮済み形式などの事前除外
- FileSystemWatcher + USN Journalによる監視補完
- 変更・新規ファイルだけを自動再圧縮
- Windows Serviceによるバックグラウンド監視
- SQLiteによる永続キュー、再試行、再開
- 長いパス・日本語パス対応
- 9～17ptのGUIフォント変更
- ログローテーションと重複WARN抑制

## 動作環境

- Windows 11 x64
- ローカルNTFSボリューム
- 配布版は .NET 10 自己完結の単一EXE

ネットワーク共有、UNCパス、NTFS以外のファイルシステムは対象外です。

## 基本的な使い方

1. WACMを起動します。
2. 「圧縮」タブへ対象ファイルまたはフォルダーを追加します。
3. 圧縮方式を選びます。
4. 必要に応じて「高速解析」で内容を確認します。
5. 「圧縮開始」を押します。

アーカイブ用途で書き換えが少ないデータには、圧縮率を重視する **LZX** が分かりやすい選択肢です。頻繁に書き換えるデータでは **NTFS** が扱いやすい場合があります。

詳しい操作は [取扱説明書](WACM_manual.txt) を参照してください。

## 監視サービス

「監視」タブでフォルダーを登録し、Windows Serviceをインストール・開始すると、変更または追加された対象だけをバックグラウンドで再圧縮できます。

サービス実行ファイルはWindowsのProgram Files配下に保護コピーされ、設定・ログ・状態DBはProgramData配下のWACM専用領域に保存されます。GUIを終了してもサービスは継続します。

## 安全設計

- 圧縮対象そのものを削除する機能はありません。
- フォルダーのシンボリックリンク、ジャンクション、マウントポイントを追跡しません。
- ハードリンク、暗号化、オフライン、読み取り専用などは安全側で除外します。
- サービス削除時も、圧縮済みファイルの圧縮状態は変更しません。
- WOF/NTFS圧縮はWindowsの透過圧縮であり、論理ファイル内容を別形式へ変換するものではありません。

重要なデータを初めて処理するときは、バックアップを用意し、小規模なテスト対象で動作を確認してから利用してください。

## ビルド

必要環境:

- Windows x64
- .NET 10 SDK

リポジトリのルートで `Build-Release.ps1` を実行すると、restore、Release build、自動テスト、Single-file Publish、単一EXEのスモークテストを順に実行します。

```powershell
.\Build-Release.ps1
```
